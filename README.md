# NIST CSF 2.0 Risk Assessment
### Information Security Risk Assessment | HIPAA-Covered Community Health Organization

## Overview
A complete information security risk assessment conducted for a fictional community health education organization using the NIST Cybersecurity Framework (CSF) Version 2.0 as the governing framework, with specific attention to HIPAA Privacy and Security Rule requirements.

## What's Included
- 11 identified risks across all 6 NIST CSF 2.0 Functions
- Likelihood × Impact risk scoring methodology
- Color-coded risk register (Critical, High, Medium, Low)
- HIPAA Security Rule citations mapped to each finding
- Prioritized remediation roadmap with assigned owners and timelines

## NIST CSF 2.0 Functions Assessed
- **Govern** — Risk management strategy, policy, and accountability
- **Identify** — Asset inventory, data flows, and risk analysis
- **Protect** — Access controls, MFA, device security, data handling
- **Detect** — Monitoring and anomalous access detection
- **Respond** — Incident response planning and awareness training
- **Recover** — Backup procedures and recovery planning

## Skills Demonstrated
- NIST CSF 2.0 risk assessment methodology
- HIPAA Security Rule application and regulatory mapping
- Risk identification, scoring, and prioritization
- Remediation planning and control documentation
- GRC analyst deliverable production

## Tools & Frameworks
- NIST Cybersecurity Framework (CSF) Version 2.0
- HIPAA Privacy & Security Rules
- Likelihood × Impact risk scoring (aligned to NIST SP 800-30)
- MITRE ATT&CK (referenced for threat context)

## Note
This assessment was conducted on a fictional organization as a demonstration of NIST CSF 2.0 risk assessment methodology. All findings reflect realistic risk patterns in a HIPAA-covered, resource-constrained nonprofit setting.
